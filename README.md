# [FlashLearn](https://flashlearn-production-8558.up.railway.app)

SaaS-платформа для интервального повторения: колоды, карточки, обучение по SM-2, публичные колоды и админ-инструменты.

## Возможности
- Регистрация/логин, JWT + refresh token
- Личные и публичные колоды
- Категории колод (включая предустановленные категории)
- Режим повторения карточек по алгоритму SM-2
- Персональные настройки повторения (кол-во новых карточек, модификатор интервалов)
- Админ-панель:
    - добавление глобальных категорий
    - массовое создание колод для всех пользователей
    - импорт колод из CSV для всех пользователей

## Админка и CSV-импорт колод

CSV-импорт доступен в админ-панели. Файл может содержать:

1) **метаданные колоды** (в начале файла, по одной строке),
2) **строки карточек**.

Поддерживаются разделители `;` и `,`.

## Шаблон CSV для загрузки колоды

Скопируйте этот шаблон в файл `.csv`:

```csv
title;Java Core
category;Java
public;true
description;Базовые карточки по Java

front;back;hint
Что такое JVM?;Java Virtual Machine;Запускает байткод
Что делает final в Java?;Запрещает переопределение/изменение;Ключевое слово языка
```

### Что означают поля

- `title` — название колоды
- `category` — категория/тип колоды
- `public` — публичность (`true` или `false`)
- `description` — описание колоды
- `front` — лицевая сторона карточки
- `back` — ответ
- `hint` — подсказка (необязательно)

Если метаданные не указаны, система применяет значения по умолчанию.


## Стек

- **Backend:** Java 21, Spring Boot 3, Spring Security (JWT), Spring Data JPA, Flyway, PostgreSQL
- **Frontend:** React, TypeScript, Vite, Tailwind, Zustand, Axios
- **Инфра:** Docker Compose (PostgreSQL для локальной разработки)
